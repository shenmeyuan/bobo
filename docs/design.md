# Bobo 的界面与角色设计

平时只保留透明桌宠与输入胶囊；聊天、照料、会话历史和任务结果在桌面气泡中展开。记录与设置窗口按需打开。界面采用深色层次、系统字体、半透明材料、细边缘与弹簧过渡，并适配减少动效和透明度等系统偏好。

六个生命周期阶段使用统一的橙色胡萝卜、绿色叶片和柔软绒面材质方向。原始参考由项目作者提供，角色素材为生成并整理的透明 PNG，位于 `src/assets/`。桌宠通过 SVG 分层、叶片摆动、眼睑和眼神、呼吸以及触摸/浇水反馈产生动效；当前不是实时 3D 模型或完整骨骼动画。

成长预览只改变展示，不修改真实年龄。演示截图使用独立临时存档与示例内容，不读取真实聊天、任务或账户额度。
