# Bobo 0.2：观察、长任务、可执行验收与用量账本

2026-10-27。本版不要求迁移原有工作入口；外部会话只观察，Bobo 自己创建的任务才可按原规则接续。没有新增在线评测或模型费用，不宣称提高模型成功率或节省比例。

## 使用入口

1. 打开 Bobo 的「偏好设置 → 其他窗口的工作」。分别开启 Codex 或 Claude Code 观察，默认关闭。
2. 桌宠气泡的「任务与结果」、管理窗口的 Agent 页都显示外部会话；需要继续或处理权限时回原工具。
3. 新建任务时可展开「运行期限与预算」。默认不限执行时间，取消旧的固定 30 分钟终止；安静状态默认 3 分钟，只提示、不停止进程。
4. 任务结束后，在「检查条件与接续预算」添加 `运行 Node 测试（手动）`，填写工作目录内的 `.test.js` / `.test.mjs` / `.test.cjs` 文件，保存后点击「运行所列测试（执行项目代码）」。
5. 展开「任务用量账本」查看每次执行、接续和相关调度的已回报用量。

## 会话观察

- Codex 使用本机 CLI 的官方 App Server 协议，只发送 initialize / initialized / thread/list。每分钟读取当前项目最近最多 40 条记录，或点击刷新；不发送 turn/start、resume、interrupt 或压缩请求。不会产生模型推理调用。CLI 太旧或请求失败时明确显示不可用，并保留带时间的旧记录。
- 独立 App Server 的 notLoaded 状态不能证明另一个窗口的工作是否仍在运行，因此显示「已有会话记录 · 实时状态未知」。不通过扫描进程或沉默时间猜测任务已完成。
- CC 在用户点击开启后，合并写入本机 Claude 设置中的状态 Hooks；保留其他配置和 Hooks，修改前备份，重复安装不叠加。支持 CLAUDE_CONFIG_DIR；暂支持 macOS/Linux。工具策略可能禁用 Hooks；已有会话通常需要恢复或新开后生效。
- Hook 在本地生成有限大小的元数据文件，Bobo 每 2 秒消费。只保存会话标识、项目路径、事件类型和时间，不保存原始提示词、工具输入/输出、压缩摘要或 transcript 路径。读取 Codex 返回值时也丢弃 preview/历史内容。元数据不主动发送给调度模型，用户询问时可通过工具按需读取。
- CC 的 Stop 表示本轮结束，不表示用户整项任务验收通过。超过 5 分钟无事件的活跃状态显示待刷新。等待用户的状态转变仅提醒一次，遵守安静模式；观察不提供自动接管权限。Bobo 自建会话不会重复出现在观察列表。
- 关闭 CC 观察只移除本次 Bobo 安装的 Hooks。关闭应用时不再处理新事件，残留旧进程的 Hook 队列有数量上限；不修改原工具权限。

## 长任务规则

- 可选执行期限为每次尝试 1～1440 分钟，到期请求停止并进入需要处理状态，不自动重试期限终止。
- 安静提示可设为 1～120 分钟，安静本身不触发恢复或杀进程。已有网络/限额/重复故障的有限接续规则保留。
- 收到执行器用量报告后检查任务链 Token 阈值；达到则请求停止并阻止新尝试。CLI 可能只在轮末报告用量，停止还存在延迟，**不是运行期间的硬计费上限**。用量未知时仍阻止有预算阈值的接续。

## 可执行验收

- 保存条件、执行器完成后的自动文件检查、调度模型的 verify_task 都不会执行项目测试；需要独立的用户界面动作。
- 仅运行用户列出的 Node 测试文件，固定使用 Node --test 和 argv，shell:false；每项 30 秒、捕获输出 64 KB 上限；退出码与失败信息进入检查结果。
- 测试子进程使用最小环境，不传入调度模型密钥、配置路径、NODE_OPTIONS 等变量。**测试代码仍具有用户的系统文件权限，可能读写文件或访问网络；这不是沙箱。** 只运行你信任的项目测试。当前不提供任意 shell、npm 命令或 Python 验收入口。
- 同工作目录验收运行中禁止 Bobo 派发新执行器、修改条件或重复验收；原执行进程未退出也不能运行测试。外部工具的写入不能通过 Bobo 的锁阻止。
- 保留测试文件哈希、声明输入依赖哈希和条件签名；执行期间或之后发生变化时，当前证据失效。未声明的代码依赖、网络和环境变化不在自动判断范围内。所列测试通过不等于业务目标完整通过。

## 用量账本

逐次记录首次执行与后续接续，失败尝试也保留；包含输入/输出、可用的缓存子项、执行器已报金额和未知状态。关联调度单列；服务多个任务的共享调用不能跨任务重复相加。缓存是输入子项，不再额外计入 Token 总数。金额 0 仅表示工具回报了 0，不声称免费；没有价格表时不估算总金额。任务跨度不等于人工投入分钟数。订阅剩余额度仍由独立账号接口读取，不能由任务 Token 推算。

## 验证

```bash
npm test
npm run build
npm run test:keeper
```

keeper 桌面回归使用隔离存档、临时 Claude 设置、模拟 Codex 协议进程和真实本地 Node 测试，点击观察开关、执行测试、检查账本和卸载 Hooks。不改用户真实设置，不调用模型。另有对本机 Codex 的只读 thread/list 探测；当前项目返回空列表，协议请求成功，未触发推理。

协议依据：[OpenAI App Server](https://learn.chatgpt.com/docs/app-server)、[Claude Code Hooks](https://code.claude.com/docs/en/hooks)。观察适配与工具的实际版本及配置有关。
