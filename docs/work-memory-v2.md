# Bobo 共享工作记忆 v2：第一版可用实现

日期：2026-10-08。基于 Codex/Claude Code 记忆机制对照提出的设计，独立实现 Bobo 的任务与项目记忆。本轮没有使用披露源码构建程序，没有请求付费模型，没有改动实际模型配置。

## 怎么使用

1. 在「偏好设置」选择项目目录，在「项目记忆」保存工作规则、偏好或参考位置。后续新对话和新任务会读取当前项目的记忆。可以明确说「记住：这个项目的金额使用整数分」，让 Bobo 保存你本轮的原话；普通临时需求不会自动保存为长期规则。
2. 在任务气泡的「记住这项工作的纠正」中，可将已确认的纠正点击「记为项目规则」。保存时仍需处于该任务原项目目录。
3. 在任务的「检查条件与接续预算」为某个产物添加「输入依赖」，每行一个工作目录内的相对路径，例如 `source.csv`。保存后点击「核查当前产物」，才能建立包含输入版本的新证据。
4. 输入文件变化，即使输出原封不动，相关旧检查也显示过期。重新检查会产生新版本，保留旧检查曾通过的历史。更改验收条件也要求复核；只调整预算不会让检查失效。
5. 交接上下文默认约 8000 个本地估算 Token，可调至 512～32000。要求、撤销标记与必要证据完整保留；报告片段和参考位置可按预算省略，完整公开报告仍可回查。必要内容本身超预算时不启动新的执行器，先拆分任务或提高预算。
6. 在设置页「撤下记忆」。后续调用明确带有 revoked 标记，原生会话中曾收到的旧规则也应停止沿用。已经运行中的 Agent 不会因此即时收到修改。

## 实现与边界

| 部分 | 已实现 | 范围 |
| --- | --- | --- |
| 工作账本 | 要求、验收、纠正、检查点、证据分类型保存；版本、来源、历史、序号 | 只观察 Bobo 管理的任务 |
| 增量更新 | 内容指纹去重；会话标识、公开报告、终态和纠正等实质变化触发更新 | 序号是 Bobo 记忆变更边界，不是原生 CLI 全量日志游标 |
| 项目记忆 | 用户确认、精确保存、去重、关键词检索、撤销与重启持久化 | 每项目最多 100 条有效、每条最多 2000 字符；不自动将 Agent 自报变成可靠经验 |
| 项目隔离 | 规范路径及 Git common directory 定位；共享仓库指导，区分 worktree 与任务 | 普通目录初始化 Git 后保持身份；目录移动不自动迁移指导 |
| 证据依赖 | 输出哈希、声明输入哈希、验收条件版本 | 不推断全部隐含依赖；未声明环境、接口或业务语义变化仍需独立验证 |
| 上下文装配 | 要求优先、完整片段选择、超预算阻止新尝试、原文档案引用 | 相同工具继续沿用原生 session；不读取隐藏推理或改写原生压缩 |
| 调度历史 | 按完整消息控制近期聊天预算；每轮输入预算检查 | 未实现自动提炼全部闲聊，也不保证更早未保存的聊天能回忆 |

项目指导与任务证据不共用有效性：同仓库 worktree 可以读取项目指导，但验收证据仍绑定原任务与当前文件版本。任务的明确新要求优先；记忆本身不提供新权限或扩大任务范围。

Token 使用本地 `o200k_base` tokenizer 分块估算，限制长串文本的计算耗时；分块边界、模型别名与其他执行器 tokenizer 会产生差异。界面同时显示实际传输字符数。估算只覆盖 Bobo 注入的文本，不包含原生会话历史、工具 schema 的执行器内部开销、隐藏推理、服务端计费或将来生成的输出。因此它是装配门槛，不是实际任务费用硬上限。用量仍以执行器回报为准。

已启动新应用，并验证真实存档迁移后宠物身份、代数、出生时间和原配置路径保持一致；迁移前已备份原存档。兼容原 version=1 存档，新增独立 workMemory 字段，不改动宠物年龄、身份或原对话数据。原子写入；格式无法读取时保留原文件。旧报告无法凭空补回已遗失的文本；旧检查没有输入哈希时也不能声称输入已核对。

## 验证

- 90 项单元回归通过，包括新增跨项目/worktree 隔离、Git 初始化前后作用域、去重与撤销、跨对话请求注入、记录增量与重启、输入变化、旧验收复核、预算阻止启动/接续、提高预算后完整保留要求。
- TypeScript/Vite 构建、macOS 应用打包通过；打包后的实际 Bobo 可执行文件再次通过共享记忆桌面流程。
- 六套隔离 Electron 流程通过：桌面交互、任务接续、自动照看、原有报告记忆、权限拒绝、新共享记忆。真实本地子进程验证交接、档案读取、依赖变化和预算阻止；模拟 API/CLI，不消耗实际模型额度。
- 新桌面流程实际点击保存规则、添加输入依赖、设置预算、接续与撤销；重启后新会话的执行器收到撤销状态；没有 renderer 错误。

测试命令：`npm test`、`npm run build`、`npm run test:desktop`、`npm run test:workflow`、`npm run test:supervisor`、`npm run test:memory`、`npm run test:permissions`、`npm run test:work-memory`。

## 尚待验证与下一阶段

这一版落实任务证据、用户确认的项目指导与装配预算。自动生成经验候选、验证与增量整合、CC compact 生命周期 hooks、Codex App Server 生命周期接入仍未实现；没有直接调用原生 compact 接口。

没有进行新的真实模型长任务对照，不能据此宣称优于 Codex/CC、提高成功率或节省费用。后续应固定相同底层模型、任务、断点、权限和预算，比较原生继续、现有 Bobo、新记忆，计算完整执行/调度/检索成本及实际人工干预。先证明正确性收益，再决定是否增加付费经验提取。
