# Bobo 自动照看 · 2026-10-04

工作交给 Bobo 后，由它自己检测中断并有限恢复。用户不需要先发现中断，再告诉它让谁接着做。

## 已实现的流程

| 状态 | Bobo 的动作 |
| --- | --- |
| 明确网络错误，原进程已退出 | 等待约 10 秒，优先恢复原 Agent 的确切会话 |
| 明确限额 | 在允许名单中找已安装、未在本任务报限额的工具接手 |
| 用户配置的文件检查不通过 | 携带失败条件修正一次 |
| 三分钟没有输出，进程仍在 | 只标记安静，不重启、不启动重复任务 |
| 登录、权限、未知错误 | 暂停，通知用户 |
| 同类故障再次出现、次数或用量阈值阻止接续 | 暂停，通知用户 |
| 用户停止工作 | 停止最新执行，取消待恢复，不自动重启 |

默认最多 3 次尝试，含首次；可在任务详情调整为 1～10。Token 阈值检查下一次尝试前的已回报用量，有未知用量时暂停；不是执行期间硬上限。监控由本地规则和进程事件完成，不反复调用 LLM。恢复执行本身仍会产生用量。

新任务默认照看。设置中可关闭，也可选择限额时允许接手的工具；默认 Codex、Claude Code、Trae。每项任务保存派发时的名单，任务详情可以单独修改。旧版历史任务不会因为升级而自动重跑。暂停照看仅取消恢复，正在运行的任务仍继续；停止任务则会终止执行。

## 接续与纠正

同工具有明确会话 ID 时使用原生 resume；跨工具传递原始目标、用户检查条件、之前结果摘录、实际文件变动和有效纠正。始终使用原工作目录，不扩大首次任务的写入权限。等待进程实际退出；异常重启后若保存的 PID 仍存在，先阻止重复执行。

任务详情中可以添加、撤下纠正，也可以对 Bobo 明确补充任务要求。纠正保存在这条任务链，下一次接续携带，**不会立即注入正在运行的 CLI**。目前没有跨项目长期偏好学习。

## Trae 接入

这台电脑的 `~/.local/bin/traecli` 是 Coco v0.121.1，支持 `--print --output-format stream-json`，不是公开版 TraeCode CLI 2 的 `exec`。Bobo 已按此版本接入，支持 `BOBO_TRAE_PATH` 指定路径。

已通过 Bobo 的真实执行适配器获得 `BOBO_READY`、会话 ID 和实际 usage。此验证仅为无工具问答，不证明所有编辑、命令与恢复场景都可用。当前读取 Coco 的 input_tokens 时不重复叠加缓存读取量；CLI 返回费用 0 不等于订阅免费。

默认 plan，禁用文件修改、Bash 和交互提问工具。允许修改后使用 default 模式和文件读写工具白名单，其他操作遵守原工具权限，没有启用 bypass_permissions，也没有额外的系统级沙箱。此版本通过 argv 接收需求，使用 shell=false；任务文本不应包含密钥。

## 验证与边界

- 43 项单元测试通过，覆盖重复故障、原生会话、限额换工具、未知预算、旧进程退出等待、手动停止、重启幂等、纠正携带和缓存计数。
- 自动照看 Electron 测试：本地测试子进程报 429 → 自动切换适配器 → 携带用户纠正 → 文件检查通过 → 一次最终宠物通知。没有调用人工 resume。另验证等待期间停止后不会恢复。
- 原桌面交互、手动接续与重启存档回归通过。构建通过。
- 测试子进程模拟故障，不冒充供应商实际故障恢复能力。Trae 的真实问答已单独验证。

**目前只照看 Bobo 发起的工作，不会自动接管你在 Trae CN / CC / Codex 里自行打开的任务。** 应用关闭后不继续监控；正常退出会停止正在执行的 Bobo 子进程。没有业务语义级自动验收、自动订阅额度查询或运行中硬预算。

此次已经验证减少了“发现故障后手动转交”的步骤，尚未证明比熟练用户更省 Token 或完成率更高。之前三组小样本交接实验的局限和结果仍成立，不能作为效率领先依据。

## 使用

打开 `release/mac-arm64/Bobo.app`，点击桌宠，在「＋」里直接选择 Trae / Codex / Claude Code，或者用自然语言交代工作。任务详情显示照看状态和恢复记录。「设置 → 让 Bobo 照看工作」配置新任务规则。仍需先选择工作目录，按任务需要开启文件修改。
